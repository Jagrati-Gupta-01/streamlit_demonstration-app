### Mortgage Calculator
This code builds an interactive Mortgage Repayments Calculator using Streamlit. It allows users to input key loan details such as home value, deposit, interest rate, and loan term, and then computes important financial metrics related to the mortgage.

The application calculates the loan amount, monthly repayment, total repayment, and total interest payable using standard amortization formulas. These results are displayed in a clean, user-friendly dashboard format with key metrics highlighted.

Additionally, the code generates a detailed payment schedule, breaking down each monthly payment into principal and interest components while tracking the remaining loan balance over time. This data is stored in a Pandas DataFrame for structured analysis.

Finally, the app visualizes the loan progression by plotting the remaining balance per year using a line chart, helping users understand how their debt decreases over the life of the loan.
